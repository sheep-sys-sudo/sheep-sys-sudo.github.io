前言

今天所幸把CC链全部写完吧，这篇不止是CC2和CC4
我们知道，除了commons-collections3，我们还可以用commons-collections4
这个库出现了新的链子
CC2
为什么呢?
3.2.1没有实现TransformingComparator类的Serializable接口，即无法被序列化
而commons-collections4实现了，即可以被序列化
在这，我们也学习新的入口类方式，也会出现在我们今后的学习之中
